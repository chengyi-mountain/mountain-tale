# 山间故事 · Mountain Tale

> 一款2D俯视射击小游戏，HTML5 Canvas 开发，单文件即开即玩。

## 在线玩

👉 [https://chengyi-mountain.github.io/mountain-tale/](https://chengyi-mountain.github.io/mountain-tale/)

电脑、手机浏览器直接打开就能玩。

## 游戏模式

- **闯关模式**：共200关，逐关递增难度，中途阵亡需从第一关重新开始
- **无尽模式**：无限波次，看你能撑多久

## 操作方式

### 电脑
- **WASD** — 移动
- **鼠标** — 瞄准，左键射击
- **1/2/3/4** — 切换武器
- **R** — 换弹
- **Esc** — 暂停菜单

### 手机
- **左半屏拖动** — 移动摇杆
- **右半屏点按** — 朝该方向射击

## 武器系统

- **手枪** — 初始武器，稳定可靠
- **冲锋枪** — 高射速，近战利器
- **霰弹枪** — 近距离爆发
- **手雷** — 范围伤害

## 游戏特色

- 🎯 **波次系统**：每关敌人数量和强度递增
- 🤖 **敌人AI**：敌人会主动追击、射击
- 🧱 **掩体系统**：利用地形躲避子弹
- 📦 **道具掉落**：击杀敌人随机掉落弹药、护甲
- 🗺️ **小地图**：左上角实时显示敌人位置
- 🏆 **本地排行榜**：记录最高关卡和最高分
- 🎵 **背景音乐 + 音效**：开枪、换弹、命中音效
- 📱 **手机触屏支持**：虚拟摇杆 + 触控射击

## 暂停菜单

按 Esc 或点击暂停按钮，可：
- 继续游戏
- 开关声音
- 返回主菜单

## 技术

- 纯 HTML + CSS + JavaScript，单文件
- HTML5 Canvas 渲染
- Web Audio API 合成音效
- 部署：GitHub Pages
